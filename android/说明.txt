Nai学长工作室 · 安卓独立版（以电脑版 1.5.2 为基准）

这是装在手机上就能用的独立软件，不连电脑，不遥控工作室。
应用在手机里起一个只监听 127.0.0.1 的小服务，发现、换角草稿、出图都在这台手机完成。

只需要两把钥匙：
  · NovelAI Token：出图
  · DeepSeek API Key：用中文写角色槽、优化咒语

网络分流：
  · 搜 AITag / 写角色可以走代理
  · 出图默认直连，避免开了代理反而生成不了
  · 设置里填 Clash HTTP，例如 http://127.0.0.1:7890，也可只填 7890
  · 不要只开全局 VPN/TUN：Java 出站看不到 TUN，应用会自动探测 7890/7897
  · 还被网站拦：设置里点「测试在线库」或「打开在线库过验证」

能做：
  · 搜 AITag 在线库并收藏入库；在线挂了也能用内置样例
  · 必须先收藏入本地库，才能换角、换画风和生成
  · 作品页能看原图咒语、角色槽和换角后的草稿预览
  · 本机打进电脑同款全量 D 站角色包（char_tag_index，约 35 万角色）+ 明日方舟库 + OC / 自定义
  · 内置画风 + 自定义画风
  · DeepSeek 把自然语言写成角色槽
  · 确认后加入本机生成队列（默认免费档，同一任务可出多张；可取消 / 手动重试）
  · 草稿可手改底栏、负面、seed、步数
  · 入库完成显示「可换角生成」后才能换角
  · 图库按生成任务分组，点进去才看这一组图，可删除这组
  · 生成后自动存到系统相册「Nai学长工作室」
  · 收藏就是入本地库：作品信息、咒语和图片留在手机
  · 后处理流水线：本机 2x 超分 + 清元数据 + 存相册

不做：
  · 不遥控 Windows 工作室
  · 不读电脑待生成队列
  · 不配对电脑、不填电脑服务地址
  · 不打包电脑 ANR 打码模型（上百 MB，不在这个包里）

直接下载（已打好的 debug 安装包）：
  android/download/NaiXueZhang-Phone-1.5.2.apk
  手机浏览器点开 raw 链接会开始下载。装完后允许未知来源，打开「Nai学长工作室」。

用法：
  1. 直接装上面的 APK；或用 Android Studio 打开本目录，JDK 17，Run 到手机或模拟器。
     或在本目录执行 gradlew.bat assembleDebug，安装 app/build/outputs/apk/debug/app-debug.apk。
  2. 桌面图标和启动页是独立应用壳，不是浏览器标签。
  3. 打开应用后点「设置」，粘贴自己的 NovelAI Token 和 DeepSeek Key。
  4. 在「发现」搜图，点☆入本地库；本地库里才能换角、选画风、排队生成。
  5. 图库按任务分组，点进去看同一组图；可开关超分/清元数据。
  6. 应用只监听手机自己的 127.0.0.1:18797，不连电脑上的 8797。

Token 只写进应用私有存储，日志里不会打印。
电脑上的 /m 仍是工作室预览页，和这个独立 APK 不是同一条产品路径。
