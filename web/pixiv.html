登录与账号设置

当前高亮账号就是唯一上传账号；登录哪个账号，就只上传到哪个账号。

1. 新建槽点「新建账号槽」起本地配置
2. 通行密钥浏览器里用 Pixiv 通行密钥登录（完成账号绑定）
3. 检测登录绿标后再上传；勿用密码管理器乱填 token

将弹出专用 Chrome（当前账号配置在 data/pixiv_chrome_profiles/账号ID），选 通行密钥 登录。
若 Passkey 不可用：先在该 Chrome 右上角登录你的 Google 账号，再重试通行密钥。

弹出浏览器自动填表；更推荐用「通行密钥」页。

Token 获取说明 / 常见错误
  1. 双击 Get-Pixiv-Token.bat 在浏览器里登录 Pixiv。
  2. 或安装 Pixiv OAuth 扩展，复制 refresh_token（不是 access_token）。
  3. 勿用密码管理器自动填充到 token 框。
