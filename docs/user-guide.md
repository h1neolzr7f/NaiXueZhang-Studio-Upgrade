# Nai学长工作室 · 小白使用指南

这份说明给第一次打开软件的人。客服小祥回答「怎么用」时会检索它，不调用模型，也不读取你的图库文件。

## 两位助手，不要混台

屏幕左右边缘可以划开 Live2D 助手；完整对话在「更多」里。

| 助手 | 位置 | 负责 | 不负责 |
|---|---|---|---|
| 客服小祥 | 左侧 / `/butler?agent=sakiko` | 用法教学、图库体检、采集、收藏、后处理、设置、排障、知识库 | 出图、换角、导演、改待生成队列、投稿准备 |
| 助手凑企鹅 | 右侧 / `/butler?agent=tomori` | 选材、换角、出图、导演、待生成队列、投稿草稿 | 采集、改设置、删成果、教软件用法 |

凑企鹅是互联网上高松灯的二创称呼，不是另一个产品账号。两人共用你配置的同一套 AI API，但工具白名单分开；越权动作会被拦下，需要切换助手。

划过立绘可以互动。布置任务：在侧栏输入框或完整对话里用命令式说法，例如「检查图库状态」「从待生成里每个出 2 张」。提问（怎么、如何、为什么）只回答，不创建任务。

## 先做这三步

1. 打开「设置」，填写文本模型 API 和 NovelAI Token。密钥只保存在本机。
2. 让图库有第一批图：用「爬虫」采集，或在「图库」切到自选库 / Q群 后把本地图或文件夹拖进去。没有图时不能启动采集。
3. 在「图库」搜索、收藏，或加入「待生成」，再把出图交给助手凑企鹅。

## 主导航八项

1. **图库** `/`：按标题、标签、Prompt 搜索本地作品。切到自选库或 Q群 后可拖入本地 NovelAI 图，每一批自动进一个文件夹，文件夹可合并后再加入批量换角。查看和拖入都不消耗 Token。
2. **生成库** `/generated`：按系列查看生成结果；删除进回收站，可恢复。
3. **工作台** `/studio`：导入作品、改尺寸 / steps / scale / sampler / seed，准备或确认生图。
4. **换角** `/remix`：替换角色或画风。确认生成前不调用 NAI。
5. **待生成** `/queue`：出图清单。只有凑企鹅能改队列。
6. **爬虫** `/progress`：Pixiv 采集进度、搜索词、榜单、隔离区。由小祥确认后启动或停止。
7. **分类** `/nai-tags`：从已验证 NAI Prompt 做分面，不是 Pixiv 标签列表。
8. **发布** `/pixiv`：准备标题、简介、标签、分级。实际上传必须你在页面上核对。

## 更多里的页面

- **导演台** `/director`：去背景、线稿、草图、上色、表情、清理。先零费用预检，再计费确认。单次最多 40 张。
- **收藏** `/favorites`：只读书架；维护收藏找小祥。
- **参考库** `/references`：本地角色与画风资料，不调用生成接口。
- **自选库** `/codex`：独立导入页。主图库切到自选库后也可以直接拖入；只收带 NovelAI 元数据的图。
- **后处理** `/pipeline`：超分、必要打码、元数据。投稿只用 final 文件。
- **本地资产** `/tag-assets`：角色库与 AITag 草稿，不直接出图。
- **设置** `/settings`：API、模型、图库偏好、知识库重建。接口地址 / 代理 / 端口请到 `#ai-service` 手工填，助手不能改这三项。
- **维护** `/maintenance`：容量、孤儿文件、永久跳过清单、staging。先预览再确认。
- **运营** `/ops`：只读健康检查。
- **合规与来源** `/compliance`：作者排除、作品禁止新增、责任说明。记录只在本机。

## 花钱和确认

- 搜索、查看、预检、准备草稿：不调用 NAI，不扣 Anlas。
- 生图、批量、导演真正执行、部分后处理：确认后才可能扣费。
- HTTP 5xx 有响应时不自动重试，避免重复扣费。
- 真实 Pixiv 上传、账号和密钥始终由你控制。

## 知识库

内置文档包括 README、本指南、升级说明、免责声明、负责任使用和安全说明。客服小祥先用固定主题，再检索这些文件。可在设置页增量重建；没有路径或网址参数，也不会索引你的私人图库。
