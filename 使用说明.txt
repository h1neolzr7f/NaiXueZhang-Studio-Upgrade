  Nai学长工作室 使用说明
═══════════════════════════════════════════

第一次启动（小白便携包）
  1. 把 ZIP 完整解压到普通文件夹，不要直接在压缩软件里运行。
  2. 双击“一键启动.bat”。
  3. 等待浏览器自动打开 http://127.0.0.1:8797/。
  4. 便携包已经内置 Python 和依赖，不需要另外安装开发环境。
  5. 重复双击只会重新打开浏览器，不会启动第二份服务。
  6. 本包是升级版 v1.5.2。需要旧版冻结包时请使用稳定版 v1.4.0。

轻量源码包
  双击同一个“一键启动.bat”会自动调用 INSTALL.bat。
  轻量包没有 runtime 文件夹，因此电脑需要预装 Python 3.11–3.13。

首次使用顺序
  1. 打开「设置」，填写文本模型 API 和 NovelAI / 闲云 Token。密钥只保存在本机。
  2. 先建初始图库：采集，或在「图库」切到自选库 / Q群 后拖入本地 NovelAI 图。
  3. 图库有数据后，再创作、换角、发布。
  · 空图库时首页会显示引导横幅，可直接跳转采集页或自选库。
  · 拖入的每一批会自动进一个「拖入」文件夹，文件夹可合并后再加入批量换角。
  · 左右侧栏是客服小祥和助手凑企鹅，可划开 Live2D 立绘。

日常出图（电脑版主链路）
  1. 在「图库」选作品，点「用此图生成」或「换角」。
  2. 工作台可一次把本系列全部页入队；默认走 Opus 免费档，不按张扣付费 Anlas。
  3. 生成结果按源作品收在「生成库」。本机 data/generated 也按作品分文件夹：原图、已去元数据、其他文件分开。删错了可在本页回收站恢复，不会自动清空。
  4. 进程重启后，未发出的排队任务会被取消；工作台 / 生成库会提示续跑，只补未发出的页。
  5. 要发 Pixiv，打开「发布」。Pixiv 账号和 NovelAI Token 不是同一份。

主导航
  一级：图库、生成库、工作台、换角、发布、设置。
  「更多」里：待生成、爬虫、分类、导演台、管家、后处理、运营、合规等。页面都在，只是入口收进菜单。

第一次采集（无需账号，推荐）
  1. 打开「更多」→「爬虫」，或访问 http://127.0.0.1:8797/progress。
  2. 填写搜索标签（每行一个）或画师 UID。
  3. 建议勾选“浏览器渲染”（更稳，需本机 Chrome/Edge）。
  4. 可选：填 HTTP 代理（如 http://127.0.0.1:7897）。
  5. 勾选“启用直连采集”并保存，再执行一轮或持续采集。
  · 无账号自动走 Pixiv 公网页面通道，只读取公开数据，不登录、不改动远端。

进阶：配置 Pixiv 账号（可选）
  1. 打开 http://127.0.0.1:8797/pixiv，用通行密钥登录或添加 refresh_token。
  2. 有账号后采集自动升级为 Pixiv App API 通道（保守限速，防封号）。
  3. 令牌保存在本机加密文件，不会进入发行包或备份。

入库保证
  · 一个 Pixiv 作品保持为一个图库作品。
  · 多图逐页验证，只保存含有效 NovelAI 元数据的页面。
  · 普通图片、SD、ComfyUI 不会入库。
  · Pixiv 标签用于分类；NAI prompt 标签另行解析。
  · 断点和拒绝回执保存在本机，不通过图库 API 暴露原图 URL。

手机版
  安卓独立应用在 android/。装到手机后不需要先开电脑工作室，也不遥控电脑。
  小白三步：设置里填 NovelAI 和 DeepSeek → 发现里收藏入本地库 → 本地库换角/画风后排队生成。
  只填 NovelAI Token 和 DeepSeek。Token 每行一个，几个就能并发几路。在线库只负责搜图收藏；必须先入库才能换角色和生成。
  搜图可走代理，出图默认直连。Clash 填 HTTP（7890），不要只开全局 VPN。还打不开就到设置点「打开在线库过验证」，或先打开内置样例把换角跑通。收藏就是入本地库，可离线换角。作品页能看原图咒语和换角后的草稿预览。
  生成后会跑本机流水线（2x 拉伸 + 清元数据）并按同一任务收入图库。打码模型不打进 APK。
  换角请点开搜索，输入即搜；中文会自动对英文 tag。本机打进电脑同款全量 D 站角色包（约 35 万），也有明日方舟库、OC / 自定义和画风。
  入库完成才能换角。队列可取消或手动重试。草稿可手改咒语。图库按任务分组，可删一组。
  电脑双击“启动手机版.bat”只用来在电脑浏览器里预览 /m 布局。
  本 Windows 一键包不含 APK。

日常启动
  双击“一键启动.bat”。重复双击只会打开图库，不会重复启动服务。

本地数据
  data/aitag.db     兼容文件名；保存图库数据库
  data/images/      已验证图片
  data/pixiv_nai_*.local.json  私有任务与断点，禁止提交 GitHub
  data/nai_token.local.json    NovelAI / 闲云账号池，禁止提交
  data/generated/              生成图，禁止提交

发行包默认不带 Pixiv 图片或用户数据库。侧栏 Live2D 立绘随包提供。请勿将 data/images、数据库或账号文件提交到公开仓库。
