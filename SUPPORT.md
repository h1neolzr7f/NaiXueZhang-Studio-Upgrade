# Support

Nai学长工作室 is a community-maintained, unofficial project. Support is provided through GitHub and does not include support for NovelAI, Pixiv, or any other third-party service account.

## Where to ask

- Reproducible bug: open a [bug report](https://github.com/h1neolzr7f/NaiXueZhang-Studio-Upgrade/issues/new?template=bug_report.yml).
- Concrete workflow improvement: open a [feature request](https://github.com/h1neolzr7f/NaiXueZhang-Studio-Upgrade/issues/new?template=feature_request.yml).
- Security vulnerability: follow [SECURITY.md](SECURITY.md) and do not disclose exploit details publicly.
- Stable v1.4 package issue: use the [v1.4 repository](https://github.com/h1neolzr7f/NaiXueZhang-Studio).

Before opening a report, check the [user guide](docs/user-guide.md), [upgrade notes](docs/UPGRADE.md), existing issues, and the latest release notes.

## Include in a bug report

Please provide:

- application version or commit SHA;
- Windows and Python versions, when running from source;
- the smallest reproducible sequence of steps;
- expected and actual behavior;
- sanitized logs or screenshots;
- whether the action may have contacted a paid external service.

Remove tokens, cookies, API keys, account identifiers, private images, local database contents, and full personal file paths before posting.

## Support boundaries

Maintainers can help with this repository's code, packaging, documented setup, and reproducible defects. They cannot:

- recover third-party accounts or reverse charges;
- guarantee availability, pricing, or behavior of external services;
- provide or request shared credentials;
- help bypass CAPTCHAs, rate limits, access controls, bans, or platform rules;
- determine whether a user owns the rights to a particular image, prompt, character, or dataset.

The project has no guaranteed response time or service-level agreement. Well-scoped reports with a minimal reproduction and non-sensitive evidence are the easiest to investigate.
